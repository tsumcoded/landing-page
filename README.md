# landing-page

This work corresponds to the final assignment for the CSS fundamentals course on [The Odin Project](https://www.theodinproject.com/about).

### Important note

As per The Odin Project [requirements](https://www.theodinproject.com/lessons/foundations-landing-page) for this project, the design does not need to be responsive. I have not added any custom images or text, because that's not the point of the exercise, and also because I'm lazy.

### Thought process

For clarity (mostly on my side), each page section is identified by a comment 'tag' within both the index.html and style.css files.

As a finishing touch (edf7813), I have streamlined the CSS only for those declarations grouped under a common comment 'tag', so as to hopefully not make any future debugging too confusing (again, this might just be a me thing).
